# bloqueador-de-atalhos-do-windows
 Utilitário leve em C# (WinForms) para bloquear atalhos do Windows (Win, Alt+Tab, Ctrl+Esc) e evitar interrupções durante jogos. Possui interface simples, minimiza para a bandeja do sistema (System Tray) e permite ativar ou desativar o bloqueio globalmente pressionando as teclas 'O' e 'P' simultaneamente.
